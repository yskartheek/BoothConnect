# #32: GET /v1/me, who am I and where do I work

**Issue:** https://github.com/yskartheek/BoothConnect/issues/32
**What changed:**

- `GET /v1/me` (signed in) returns:
  - the user's profile: name, phone, email, preferred language, MFA state;
  - their **active** role assignments: the role, the place (state, PC, AC,
    part or polling station) and the full **path** from the state down to it,
    e.g. `S99 → PC 1 → AC 101 → Part 1 → Station 1`.
- Assignments that have ended, or haven't started yet, are left out.
- The apps will use this after sign-in to show the volunteer their booths
  and the admin their constituency.

## Steps

1. Check out the branch and prepare as for #30:
   ```powershell
   git checkout claude/issue-32-me
   pnpm install --frozen-lockfile
   pnpm infra:up
   pnpm --filter api db:deploy
   pnpm --filter api db:seed
   pnpm --filter api dev
   ```
   Keep `OTP_DEV_MODE=true` in `.env`.
2. In a second PowerShell window, sign in as volunteer A (the code is in the
   API window's log; replace `123456`):
   ```powershell
   $api = "http://localhost:4000/v1"
   Invoke-WebRequest -Method Post -Uri "$api/auth/otp/request" -ContentType "application/json" -Body '{"phone":"+919999900002"}' | Select-Object StatusCode
   $t = Invoke-RestMethod -Method Post -Uri "$api/auth/otp/verify" -ContentType "application/json" -Body '{"phone":"+919999900002","code":"123456","deviceId":"my-laptop"}'
   ```
3. Ask who you are:
   ```powershell
   $me = Invoke-RestMethod "$api/me" -Headers @{ Authorization = "Bearer $($t.accessToken)" }
   $me | Select-Object name, phone, preferredLanguage
   $me.assignments | ForEach-Object { $_.role + ': ' + (($_.path | ForEach-Object { "$($_.type) $($_.code)" }) -join ' > ') }
   ```
   **Expect:** Volunteer A's name and phone, and one line:
   `volunteer: state S99 > pc 1 > ac 101 > part 1 > polling_station 1`.
4. Repeat steps 2–3 with the admin, `+919999900001`.
   **Expect:** `admin: state S99 > pc 1 > ac 101`.
5. Without a token:
   ```powershell
   Invoke-RestMethod "$api/me"
   ```
   **Expect:** 401 `UNAUTHENTICATED`.
6. Run the tests:
   ```powershell
   pnpm --filter api test:int
   ```
   **Expect:** all pass, including "GET /v1/me".

## Pass criteria

- Steps 3–6 give the expected results.

## Known issues and notes

- Role assignments are only created by the seed so far; managing them comes
  with the admin features (Epic 4/7).
- `/me` shows where a user works; restricting every other endpoint to those
  places is #33 (GeoScopeGuard).
