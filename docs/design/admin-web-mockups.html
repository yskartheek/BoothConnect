Admin portal · concept

BoothConnect admin portal

Concept screens for administrators, based on spec §5.3, §8 and §9.3 and the PDF roll-import design (#92). The sample figures are synthetic but consistent: AC 040 Patancheru and Part 408 match the sample roll analysed in #92. On a phone, scroll each screen sideways; the portal is built for laptop and desktop screens.

Overview

  • Opens on the admin's own area, with the four numbers that matter most and a change from last week.
  • Field progress per part, so gaps like an unassigned booth stand out.
  • “Needs attention” turns problems into a to-do list. Conflicts are shown for information only, because volunteers resolve them (spec v1.1).

Navigation

The sidebar follows spec §9.3. The review queue is gone because volunteers edit directly (spec v1.1). Campaigns, form configuration and privacy settings are later milestones.

Data and privacy

  • Record-level data is only shown to roles scoped to that area.
  • Aggregates hide groups under 10.
  • Exports default to aggregates and are logged.
